The originals live in Google Drive under **App Information** — the Android set in
`Screenshots v1.0/`, the iPhone set in its own folder. The file names here are the
Drive names unchanged, so the two stay easy to line up.

**The `<img>` tags carry no `width`/`height`.** Nobody has confirmed the pixel
dimensions of either set, and a wrong pair would lock the wrong aspect ratio and
squash the captures. Add them once the real sizes are known — it is worth doing,
it stops the page jumping as the images load.

Two Android screens are described in the Drive folder's own README but were not in
the folder: `04-recorder.png` (the recorder — the app's signature screen) and
`11-instant.png` (Instant mode). Neither is referenced here. The recorder is the
one screen this page most wants, so it is worth chasing.

Before publishing any screenshot, check it shows no real job number, real
contractor or real inspector's name.
